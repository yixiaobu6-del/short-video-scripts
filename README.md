# 短视频脚本模板库

短视频脚本写不出来？
**模板库帮你快速产出。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 脚本不再"难写"

- **多平台适配**：抖音/快手/B站/视频号时长建议
- **平台提示**：每个平台优化要点
- **脚本模板**：多种爆款结构参考
- **一键生成**：参数化快速生成

## 怎么用

打开 `在线生成器.html` → 选择平台 → 填写参数 → 复制脚本
