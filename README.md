# 短视频脚本模板库

> 抖音/快手/视频号 爆款视频脚本模板合集

---

## 🎯 一键生成脚本

**在线脚本生成器**：打开 `在线生成器.html`，选择分类和模板类型，输入产品信息，一键生成完整分镜脚本表格。

---

## Features / 功能特点

| 功能 | 说明 |
|------|------|
| 带货类模板 | 产品展示、种草、测评脚本模板 |
| 知识类模板 | 科普、技巧分享、行业干货脚本模板 |
| 搞笑类模板 | 段子、情景剧、反转剧情脚本模板 |
| 情感类模板 | 情感故事、生活感悟、励志脚本模板 |
| 教程类模板 | 软件教程、手工教程、学习方法脚本模板 |
| 标准模板结构 | 时间轴+画面+文案+音效完整分镜表 |
| 时长可选 | 支持15s/30s/60s三种时长模板 |
| 可直接套用 | 替换产品/场景信息即可使用 |

## Installation / 安装

无需安装，直接复制模板内容使用。

```bash
# 克隆仓库
git clone https://github.com/yourusername/short-video-script-templates.git

cd short-video-script-templates

# 查看模板分类
ls -la
```

## Usage / 使用方法

### 基础用法

1. 选择对应分类目录
2. 复制模板内容
3. 替换产品/场景信息
4. 根据实际调整时长和节奏

### 模板结构说明

每个脚本模板包含以下部分：

```
### 脚本标题

**适用场景**：[什么产品/内容类型]
**时长**：[15s/30s/60s]
**目标**：[完播率/转化率/互动率]

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-3s | 钩子画面 | 开场话术 | 悬念音效 |
| 3-15s | 核心展示 | 痛点/价值 | BGM |
| 15-30s | 行动号召 | 结尾引导 | 强调音效 |
```

### 分类详表

| 分类 | 目录 | 适用场景 | 典型时长 |
|------|------|----------|:--------:|
| 带货类 | `带货类/` | 产品展示、种草、测评 | 30-60s |
| 知识类 | `知识类/` | 科普、技巧分享、干货 | 60-90s |
| 搞笑类 | `搞笑类/` | 段子、情景剧、反转 | 30-60s |
| 情感类 | `情感类/` | 情感故事、励志 | 60-90s |
| 教程类 | `教程类/` | 软件/手工/学习方法 | 60-120s |

### 带货类模板示例

```
## 产品种草模板

**适用场景**：美妆/家居/食品类产品
**时长**：30s
**目标**：转化率

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-3s | 产品特写+使用前后对比 | "这个东西，真的绝了！" | 悬念音效 |
| 3-15s | 产品功能展示 | "先看它的功能..." | 轻快BGM |
| 15-25s | 使用场景展示 | "平时我都是这么用..." | 节奏BGM |
| 25-30s | 购买引导画面 | "链接在左下角" | 强调音效 |
```
