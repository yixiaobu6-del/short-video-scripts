# 情感类脚本模板 - 新模板

## 对话独白型

```
**适用场景**：内心独白 / 自我对话
**时长**：30-60s
**目标**：高共鸣，引发评论互动

**结构**：
1. 设定场景（5s）：一个独处的时刻
2. 内心对话（20s）：自己与自己的对话
3. 情绪释放（15s）：承认软弱/脆弱
4. 自我和解（10s）：接受不完美
5. 治愈收尾（5s）：一句温暖的话

**示例**（独白式）：
"凌晨两点，我还在刷手机..."
"心里有两个人在吵架：
一个说'你该睡了'，另一个说'只有这个时间是自己的'..."
"其实我知道，不是不想睡，是不想过明天。"
"但后来我想通了：做不好也没关系。"
"因为我们都只是普通人啊。"
```

## 时间线回忆型

```
**适用场景**：友情 / 爱情 / 亲情回忆
**时长**：45-90s
**目标**：催泪，引导分享

**结构**：
1. 现在切入（5s）：一张老照片/老物件
2. 时间倒退（10s）：回到故事开始
3. 关键节点（30s）：几个重要时刻
4. 情感高潮（10s）：最动人的那个瞬间
5. 回到现在（10s）：现在的状态/感悟
6. 主题升华（5s）：关于时间/关系的思考

**时间轴模板**：
```
2018年 → 第一次见面
2019年 → 一起经历的困难
2020年 → 最开心的时光
2021年 → 产生分歧
2022年 → 和好/分离
2023年 → 现在的状态
```

**技巧**：
- 时间越具体越有代入感
- 对话要真实，不要完美
- 结尾不要强行正能量
```
