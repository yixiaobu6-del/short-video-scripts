# 情感类脚本模板

## 故事叙述型

```
**适用场景**：情感故事 / 真实经历
**时长**：60-120s

**结构**：
1. 悬念开头（5s）：中间开始讲故事
2. 倒叙（10s）：回到故事的起点
3. 发展（20s）：相遇/相知
4. 转折（10s）：冲突/困难
5. 高潮（10s）：选择/牺牲
6. 结局（5s）：现在怎么样了

**技巧**：
- 细节描写（不要"我们很幸福"，要"他每天早上都会…"）
- 留白（情感高潮处配音乐不讲话）
- 真实感（加入具体时间地点）
```

## 生活感悟型

```
**适用场景**：人生感悟 / 成长心得
**时长**：30-60s

**结构**：
1. 一个场景切入（5s）："昨晚看到/听到…"
2. 引发思考（10s）："我突然意识到…"
3. 核心感悟（15s）：具体观点
4. 案例支撑（10s）：自己的经历
5. 呼吁/启示（5s）："所以…"

**注意事项**：
- 不要说教
- 要有具体场景
- 金句要自然，不刻意
```

## 致谢/表白型

```
**适用场景**：感谢粉丝 / 表白 / 纪念日
**时长**：30-60s

**结构**：
1. 直接对镜头说话（3s）
2. 为什么想说这些（10s）
3. 回忆具体瞬间（15s）
4. 表达情感（10s）
5. 未来承诺（5s）

**真诚最重要**，不要套路
```
