# 知识类脚本模板

## 反常识型

```
**适用场景**：打破认知 / 冷知识
**时长**：30-60s

**结构**：
1. 抛出反常识观点（5s）："你知道XX其实是错的吗"
2. 常见认知（5s）："大多数人以为…"
3. 事实真相（15s）："但实际上…"
4. 原因解释（20s）："为什么会这样？因为…"
5. 启发（5s）："所以我们要记住…"

**钩子公式**：
- "大部分人不知道…"
- "颠覆你的认知…"
- "XX年研究告诉你…"
```

## 科普解释型

```
**适用场景**：科学知识 / 行业科普
**时长**：45-90s

**结构**：
1. 生活场景切入（5s）
2. 引出科学问题（5s）
3. 由浅入深解释（20s）
4. 类比帮助理解（10s）
5. 实际应用（10s）
6. 总结（5s）

**解释原则**：
- 用比喻不用术语
- 用数字不用形容词
- 用故事不用定义
```

## 技能教学型

```
**适用场景**：语言学习 / 软件技巧
**时长**：45-120s

**结构**：
1. 痛点（5s）："你是不是经常遇到…"
2. 解决方案（5s）："其实只需一招"
3. 步骤展示（20-60s）：具体操作
4. 效果演示（10s）：做完后什么样
5. 举一反三（10s）：其他场景也能用
6. 互动引导（5s）："关注收藏，下期继续"
```

## 数据洞察型

```
**适用场景**：行业分析 / 市场报告 / 社会现象
**时长**：45-60s

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-5s | 数据震撼开场 | "99%的人都不知道这个数字" | 悬疑音 |
| 5-15s | 数据拆解 | "这个数据意味着什么？" | 科技音 |
| 15-30s | 趋势分析 | "对比去年增长了XX%" | 对比音 |
| 30-45s | 深度解读 | "背后的原因有三个…" | 讲解BGM |
| 45-55s | 未来预判 | "按照这个趋势，未来会…" | 收尾音 |
```

---

## 知识类脚本要点

1. **开场2秒抓眼球**：用数据、反常识、悬念开场
2. **信息密度适中**：每5s不超过一个核心信息点
3. **用数据说话**：数字比文字更有说服力
4. **结尾留悬念**：引导用户点赞收藏
