# 知识类脚本模板 - 新模板

## 数据可视化型

```
**适用场景**：数据解读 / 趋势分析
**时长**：45-90s
**目标**：高收藏，高转发

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-5s | 惊人数据大字展示 | "这个数字，颠覆你的认知" | 强调音 |
| 5-15s | 数据图表/动画 | "根据[权威来源]的数据显示..." | 分析感BGM |
| 15-30s | 数据变化过程 | "从XX年到XX年，变化了X倍" | 节奏渐变 |
| 30-45s | 原因分析 | "为什么会出现这种情况？" | 思考感BGM |
| 45-55s | 背后的逻辑 | "根本原因其实是..." | 揭晓音 |
| 55-60s | 启发总结 | "所以我们要记住..." | 收尾音 |

**示例**：
数据大字：中国人均年读书量4.7本
动态图表：各国阅读量排名变化
→ "我们的阅读量不到以色列的1/10"
→ 分析原因：移动互联网时代
→ 启示：信息碎片化带来的认知降级
```

## 清单整理型

```
**适用场景**：干货整理 / 避坑指南
**时长**：30-60s
**目标**：高完播率，引导收藏

**结构**：
1. 抛出主题（3s）："XX领域必知的N件事"
2. 第1点（7s）：最关键的第一条
3. 第2点（7s）：最容易被忽略的
4. 第3点（7s）：最有用的干货
5. 更多内容（10s）：快速浏览剩余内容
6. 收藏引导（3s）："建议收藏慢慢看"

**清单模板**：
```
【新手必看】XX领域的X个致命误区
误区1：XX — 90%的人都会犯
误区2：XX — 越努力越糟糕
误区3：XX — 你以为是对的
正确做法：...
```

**技巧**：
- 清单数量用3-7条，太多记不住
- 每一条配字幕+数字序号
- 节奏要快，不要在一个点上停留太久
- 最后一条要不走寻常路
```
