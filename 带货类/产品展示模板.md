# 带货脚本模板

## 产品展示型

```
**适用场景**：实物商品 / 电子产品 / 家居用品
**时长**：30-60s

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-3s | 产品特写 + 问题场景 | "你是否也遇到过这样的问题…" | 悬念音 |
| 3-10s | 产品亮相 | "直到我发现了这个…" | 哇音效 |
| 10-20s | 功能展示（3个功能） | "第一… 第二… 第三…" | 轻快BGM |
| 20-25s | 使用效果对比 | "用了之后效果立竿见影" | 对比音 |
| 25-30s | 价格+购买引导 | "现在下单只要…" | 促销音 |
```

## 测评种草型

```
**适用场景**：美妆 / 数码 / 美食
**时长**：45-90s

| 时间 | 画面 | 文案 |
|------|------|------|
| 0-5s | 开箱展示 | "今天开箱一个XX…" |
| 5-20s | 外观/细节特写 | "包装很精致，手感…" |
| 20-40s | 实际使用演示 | "我们来实测一下效果" |
| 40-50s | 效果展示 | "你们看这个效果…" |
| 50-60s | 优缺点总结 | "总结一下：优点是…缺点是…" |
| 60-70s | 购买建议 | "适合什么人买？如果…" |
| 70-80s | 价格/优惠 | "现在活动价只要…" |
```

## 痛点解决型

```
**适用场景**：功能性产品 / 服务
**时长**：30-45s

**文案结构**：
1. 痛点描述（3-5s）：重复用户内心的痛苦
2. 问题升级（3-5s）：如果不解决会怎样
3. 产品登场（5-10s）：这个东西能解决
4. 解决方案（10-15s）：具体怎么解决的
5. 限时优惠（5-10s）：现在下单的福利
```

## 价格对比型

```
**适用场景**：性价比产品 / 同类对比
**时长**：30-45s

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-5s | 价格震撼 | "这个东西只要XX元！" | 震惊音 |
| 5-15s | 同类对比 | "市面上同类产品要XX元" | 对比音 |
| 15-25s | 功能拆解 | "但功能一点都不少：1…2…3…" | 讲解音 |
| 25-35s | 品质展示 | "质量也不差，看这个细节" | 特写音 |
| 35-40s | 限时优惠 | "现在下单还有福利" | 促销音 |
```

---

## 使用场景推荐

| 产品类型 | 推荐模板 | 说明 |
|----------|----------|------|
| 新品发布 | 产品展示型 | 突出功能卖点 |
| 口碑积累 | 测评种草型 | 真实体验分享 |
| 功能刚需 | 痛点解决型 | 问题→方案闭环 |
| 价格敏感 | 价格对比型 | 强调性价比 |
