# 带货脚本模板 - 新模板

## 直播切片型

```
**适用场景**：直播间高光片段 / 产品卖点提炼
**时长**：15-30s
**目标**：高转化率

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-2s | 主播手持产品激动表情 | "家人们，这个价格我真的第一次见！" | 情绪音效 |
| 2-5s | 产品特写+价格展示 | "原价299，今天直播间只要..." | 悬念音 |
| 5-12s | 产品功能快速演示 | "你看这个效果，是不是很绝" | 快节奏BGM |
| 12-15s | 限时抢购提示 | "只有100单，手慢无！" | 倒计时音效 |

**技巧**：
- 每秒至少一个信息点
- 价格对比用视觉特效叠加
- 语音要紧凑有激情
```

## 场景演绎型

```
**适用场景**：生活场景植入 / 需求唤醒
**时长**：30-45s
**目标**：种草转化

**结构**：
1. 问题场景（5s）：日常生活中遇到的麻烦
2. 情绪共鸣（5s）："是不是你也这样？"
3. 产品出现（10s）："后来我发现了这个..."
4. 使用演示（10s）：轻松解决的过程
5. 效果对比（5s）：用前vs用后
6. 购买引导（5s）："链接在左下角"

**示例**：
场景：早上着急出门找不到钥匙
→ "你是不是也每天都找钥匙找到崩溃？"
→ "自从用了这个智能钥匙扣..."
→ 手机一键寻物演示
→ 再也不用担心迟到
```
