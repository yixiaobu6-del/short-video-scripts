# 教程类脚本模板 - 新模板

## 常见错误纠正型

```
**适用场景**：技能纠正 / 误区澄清
**时长**：30-60s
**目标**：高收藏率

| 时间 | 画面 | 文案 | 音效 |
|------|------|------|------|
| 0-5s | 错误做法展示 | "90%的人都做错了" | 警示音 |
| 5-10s | 指出错误点 | "你是不是也一直这样？" | 悬念音 |
| 10-35s | 正确步骤教学 | "正确的方法其实很简单" | 轻快BGM |
| 35-45s | 效果对比演示 | "看看差别有多大" | 对比音 |
| 45-50s | 总结互动 | "学会了点个收藏" | 收尾音 |

**技巧**：
- 错误做法要夸张，让人有"这就是我"的感觉
- 正确做法要极致简单，降低操作门槛
- 每一步配字幕关键词
```

## 拆解还原型

```
**适用场景**：复杂技能 / 专业操作
**时长**：60-120s
**目标**：深度教学，建立专业形象

**结构**：
1. 成果预览（5s）：直接展示最终效果
2. 拆解要素（10s）：需要哪些材料/工具
3. 分步拆解（60s）：按顺序拆解每个步骤
4. 关键细节（10s）：容易被忽略的关键点
5. 变式延伸（10s）：举一反三的变式
6. 作业布置（5s）："做完回来交作业"

**示例（烹饪教程）**：
展示：一盘完美的红烧肉
拆解：五花肉、冰糖、八角等
步骤：焯水→炒糖色→炖煮→收汁
关键：火候控制决定成败
变式：可以用同样方法做红烧排骨
```
