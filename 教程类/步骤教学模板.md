# 教程类脚本模板

## 步骤教学型

```
**适用场景**：软件操作 / 手工制作 / 烹饪
**时长**：30-90s

| 时间 | 画面 | 文案 |
|------|------|------|
| 0-5s | 最终成果展示 | "只需3步，你也能做出这样的效果" |
| 5-10s | 材料/工具展示 | "需要准备的东西很简单" |
| 10-30s | 步骤一（特写） | "第一步…注意这个细节" |
| 30-50s | 步骤二（关键点） | "第二步…这一步最关键" |
| 50-70s | 步骤三（收尾） | "第三步…完成" |
| 70-80s | 成果展示+互动 | "评论区交作业" |
```

## 干货分享型

```
**适用场景**：知识科普 / 技巧分享
**时长**：45-120s

**结构**：
1. 钩子（5s）：一个反常识的观点
2. 核心内容（30-60s）：3个知识点
3. 案例佐证（10-20s）：实际案例
4. 总结（5-10s）：一句话记住

**配文技巧**：
- 每10s抛一个信息点
- 关键数据用文字叠加
- 复杂内容用动画演示
```

## 对比实验型

```
**适用场景**：方法验证 / 效果对比
**时长**：30-60s

**结构**：
1. 提出问题（5s）
2. 实验设置（10s）
3. 方法A展示（10s）
4. 方法B展示（10s）
5. 结果对比（10s）
6. 结论（5s）
```
