# 搞笑类脚本模板 - 新模板

## 角色扮演型

```
**适用场景**：职场/家庭/校园情景
**时长**：20-40s
**目标**：高完播率

**结构**：
1. 角色设定（3s）：快速建立背景
2. 冲突建立（10s）：两个角色碰撞
3. 笑点推进（15s）：矛盾升级
4. 神转折（5s）：出人意料收尾

**角色搭配**：
| 组合 | 冲突点 | 笑点方向 |
|------|--------|----------|
| 老板vs员工 | 工作方式 | 互相套路 |
| 妈妈vs孩子 | 生活观念 | 代际差异 |
| 直男vs女友 | 思维方式 | 理解偏差 |

**示例**：
老板："这个方案明天要"
员工（自信满满）："好的老板"
（镜头切换：员工在百度"一晚上能学会编程吗"）
→ 观众共鸣拉满
```

## 配音恶搞型

```
**适用场景**：影视/动物/游戏素材二创
**时长**：15-30s
**目标**：高转发率

**结构**：
1. 选素材（5s）：熟悉的影视/动物画面
2. 配音切入（3s）：突兀但有趣的声音
3. 情节推进（10s）：配合画面讲新故事
4. 爆笑结尾（5s）：与原画面形成反差

**公式**：
"当[场景] + [意想不到的配音] = [搞笑效果]"

**示例**：
画面：一只猫严肃地看着镜头
配音（深沉男声）："今天我要宣布一个重要的决定..."
画面：猫转身走了
配音："这个家我是待不下去了"
```
