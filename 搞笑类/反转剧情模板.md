# 搞笑类脚本模板

## 反转剧情型

```
**适用场景**：日常搞笑 / 生活段子
**时长**：15-30s

**结构**：
1. 铺垫（5s）：正常场景设定
2. 发展（5s）：往一个方向引导
3. 反转（3s）：完全出乎意料
4. 结局（2s）：笑点收尾

**示例**：
场景：一个人很认真地在敲键盘
文案：我正在写一个改变世界的方案
镜头拉远：原来他在打游戏
文案：方案是"如何打到王者"
```

## 夸张演绎型

```
**适用场景**：情景剧 / 模仿秀
**时长**：20-40s

**核心**：
- 一个生活中常见的小事
- 夸张到极致的反应
- 观众会觉得"这不就是我吗"

**结构**：
1. 平常小事开场（3s）
2. 逐步升级（10s）
3. 爆发高潮（5s）
4. 回归平静（2s）
```

## 吐槽型

```
**适用场景**：社会现象 / 产品体验
**时长**：30-60s

**结构**：
1. 我要吐槽啥（3s）
2. 槽点1 + 演绎（10s）
3. 槽点2 + 演绎（10s）
4. 槽点3 + 演绎（10s）
5. 总结升华（5s）

**技巧**：
- 吐槽要狠，但别带恶意
- 加入自嘲增加好感
- 结尾要有金句
```
